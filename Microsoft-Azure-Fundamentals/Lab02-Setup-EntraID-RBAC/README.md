# Lab 02 - Set up new employee access Entra ID and RBAC

## Objective
Configure secure cloud identity management and resource governance by setting up a new employee profile in Microsoft Entra ID and assigning appropriate role-based permissions using Azure RBAC.

## Steps Performed
1. Navigated to the Microsoft Entra ID portal.
2. Created a new user profile for a simulated new employee with specific directory details.
3. Defined identity properties and authentication parameters within the tenant.
4. Utilized Azure Role-Based Access Control (RBAC) to assign a specific, limited security role (e.g., Reader or Contributor) to the user.
5. Verified the identity's permissions to ensure enforcement of the Principle of Least Privilege.

## Result
New user identity successfully provisioned in Microsoft Entra ID with secure, verified RBAC permissions activated.

## Skills Learned
* Identity & Access Management (IAM)
* Microsoft Entra ID Directory Management
* Azure RBAC & Security Governance
