# Lab 01 - Deploy a Static Website with Azure Blob Storage

## Objective
Host a static website (HTML/CSS/JS) directly on Microsoft Azure using the Static Website Hosting feature built into Azure Blob Storage.

## Steps Performed
1. Created a general-purpose v2 Azure Storage account.
2. Enabled the "Static website" feature in the Azure Portal.
3. Configured `index.html` as the default index document.
4. Uploaded website artifacts (HTML/CSS files) into the automatically generated `$web` container.
5. Successfully tested the live site using the Azure Primary Endpoint URL.

## Result
Static website deployed and hosted successfully using serverless Azure Storage.

## Skills Learned
* Azure Blob Storage Management
* Static Website Hosting Concepts
* Cloud Infrastructure Management
